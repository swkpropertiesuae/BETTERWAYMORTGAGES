## Raw Vector Notes
- **Outlined SVGs (`SVG_Outlined/`)** contain 100% pure Bézier curves (every letter of `betterway MORTGAGES` converted from Montserrat Bold via `fontTools`) — zero font installation required and guaranteed identical rendering everywhere.
- **Editable SVGs (`SVG_Editable_Text/`)** keep live `<text>` nodes for future copy edits (requires `Montserrat Bold`).
- **Vector PDFs & EPS Level 3 (`Print_Vector_PDF_EPS/`)** contain zero raster bitmaps and open natively as editable vector paths in Adobe Illustrator, CorelDRAW, Affinity Designer, and print prepress workflows.
